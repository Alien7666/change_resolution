這是你提的用法：**變更解析度 → 開遊戲 → 選取變更的遊戲**。設定對話框在套用模式時是鎖住的，所以這件事有自己的按鈕。

## 出事了怎麼辦

| 狀況 | 處理 |
|---|---|
| 滑鼠到不了某台螢幕 | 先按「恢復原始解析度」 |
| 程式沒反應 | 工作管理員結束 `ResolutionTray.exe`，再用 Windows 顯示設定手動調回 0.1 基線 |
| 程式說「顯示配置仍待恢復」不讓你改設定 | 那是刻意的：它知道桌面處於它造成但未驗證成功的狀態，不肯疊第二次寫入。按「恢復原始解析度」解除 |

**不要**用強制結束來跳過卡住的還原，除非你準備好手動把四台的模式與座標調回基線。
